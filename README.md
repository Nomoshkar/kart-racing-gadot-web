## Controls

### Keyboard
| Key | Action |
|-----|--------|
| `W` / `↑` | Accelerate |
| `S` / `↓` | Brake / Reverse |
| `A` / `←` | Steer left |
| `D` / `→` | Steer right |
| `Space` | Drift / Mini-turbo |
| `E` / `Shift` | Use item |
| `Esc` | Pause |

### Touch / Mobile
On a phone or tablet the game shows on-screen controls automatically:
- **Left side (SWING)** — drag the floating steering ball to steer.
- **Right side (BOOST)** — tap/hold the large button for accelerate, the smaller one for brake/reverse.
- **Item button** — tap to fire the held power-up.
- **Pause** — top-right hamburger menu.

Settings → **Display → Touch controls** lets you force Auto / On / Off.
